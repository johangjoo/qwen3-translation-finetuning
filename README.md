# Qwen3 Korean–Japanese Translation Fine-tuning

로컬 LLM의 파인튜닝이 한국어·일본어 간 번역 품질을 얼마나 개선할 수 있는지 탐구한 프로젝트입니다. Qwen3 8B와 14B 모델을 대상으로, 동일한 원문에 대한 파인튜닝 전후의 번역 결과를 비교했습니다.

번역의 자연스러움은 하나의 정답만으로 평가하기 어렵다는 점에 주목했습니다. 원문의 의미를 충실하게 전달하는지, 문맥에 맞는 표현을 사용하는지, 문장이 자연스럽게 이어지는지를 중심으로 번역 결과를 직접 검토하고, 파인튜닝에 따른 변화와 한계를 정성적으로 분석했습니다.

프로젝트 설계부터 데이터 준비 및 전처리, 모델 파인튜닝, 추론과 결과 비교·분석까지 전 과정을 직접 수행했습니다.

## 데이터셋 및 전처리

학습에는 2023년에 구축된 **라이브 스트리밍 영상 일본어 통번역 데이터**를 활용했습니다. 유튜브 영상의 발화 내용과 대응 번역문으로 구성된 데이터에서 한국어→일본어 약 70만 건과 일본어→한국어 약 70만 건을 통합하여, 총 약 140만 건의 양방향 번역 문장쌍을 준비했습니다.

개별 JSON 파일에서 원문과 번역문을 추출한 뒤, 번역 방향을 명시한 대화형 학습 데이터로 변환했습니다. 각 문장쌍은 `system`, `user`, `assistant`의 세 메시지로 구성하고, 한 줄에 하나의 학습 예제를 저장하는 JSONL 형식으로 통합했습니다.

| 메시지 역할 | 구성 | 목적 |
|---|---|---|
| `system` | 한국어·일본어 전문 번역가 역할을 지정하는 공통 지시문 | 두 번역 방향에 일관된 작업 지시 제공 |
| `user` | 번역 방향 태그와 원문 | 입력 언어와 목표 언어를 명시 |
| `assistant` | 원문에 대응하는 번역문 | 모델이 학습할 목표 응답 제공 |

한국어→일본어에는 `[Korean to Japanese]`, 일본어→한국어에는 `[Japanese to Korean]` 태그를 사용했습니다. 이를 통해 하나의 데이터셋에서 양방향 번역을 학습하면서도 각 예제의 번역 방향을 구분할 수 있도록 구성했습니다.

실제 학습에 사용한 데이터 형식은 다음과 같습니다.

```jsonl
{"messages": [{"role": "system", "content": "You are a professional Korean-Japanese bilingual translator."}, {"role": "user", "content": "[Korean to Japanese]\n그건 성향이라니까요?"}, {"role": "assistant", "content": "それは性向なんですよ？"}]}
{"messages": [{"role": "system", "content": "You are a professional Korean-Japanese bilingual translator."}, {"role": "user", "content": "[Japanese to Korean]\nできないっていうところがあるんですけどやっぱり"}, {"role": "assistant", "content": "안 된다는 게 있는데 역시"}]}
```

통합한 데이터를 무작위로 섞은 뒤, 연산 자원을 고려해 전체의 약 10%인 **14만 건을 학습에 사용**했습니다. 검증에는 학습 데이터 규모의 약 10%에 해당하는 **1만 4천 건을 사용**했습니다. 학습 시에는 `messages` 데이터를 Qwen3의 chat template에 적용해 모델 입력으로 변환했습니다.

## 번역 품질 비교 방법

학습 중 검증과 별개로, 최종 번역 품질은 **학습에 사용한 내용과 다른 문장을 별도로 입력하여 정성적으로 평가**했습니다. 동일한 원문을 Qwen3 8B·14B의 파인튜닝 전후 모델에 입력하고, 의미 전달의 충실도와 문맥에 맞는 표현, 문장의 자연스러움을 중심으로 결과를 직접 비교했습니다.

이를 통해 검증 데이터에 대한 학습 상태 점검과 실제 번역 결과에 대한 품질 판단을 구분하고, 파인튜닝으로 나타난 변화와 한계를 분석했습니다.

## 학습 환경 및 설정

학습은 NVIDIA GeForce RTX 5070 Ti(VRAM 16GB) 환경에서 수행했습니다. 제한된 GPU 메모리에서 Qwen3 8B와 14B 모델을 학습하기 위해 4-bit NF4 양자화와 LoRA를 적용했습니다.

| 항목 | Qwen3 8B | Qwen3 14B |
|---|---|---|
| 학습 방식 | 4-bit NF4 + LoRA | 4-bit NF4 + LoRA |
| LoRA rank / alpha | 16 / 16 | 16 / 16 |
| 학습률 | 0.0002 | 0.0002 |
| 학습 횟수 | 2 epochs | 2 epochs |
| 배치 크기 | 6 | 1 |
| Gradient accumulation steps | 3 | 16 |
| 최대 시퀀스 길이 | 160 tokens | 160 tokens |
| 학습 데이터 규모 | 약 14만 건 | 약 14만 건 |
| 검증 데이터 규모 | 약 1만 4천 건 | 약 1만 4천 건 |
