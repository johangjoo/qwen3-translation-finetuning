# Qwen3 Korean–Japanese Translation Fine-tuning

로컬 LLM의 파인튜닝이 한국어·일본어 간 번역 품질을 얼마나 개선할 수 있는지 탐구한 프로젝트입니다. Qwen3 8B와 14B 모델을 대상으로, 동일한 원문에 대한 파인튜닝 전후의 번역 결과를 비교했습니다.

번역의 자연스러움은 하나의 정답만으로 평가하기 어렵다는 점에 주목했습니다. 원문의 의미를 충실하게 전달하는지, 문맥에 맞는 표현을 사용하는지, 문장이 자연스럽게 이어지는지를 중심으로 번역 결과를 직접 검토하고, 파인튜닝에 따른 변화와 한계를 정성적으로 분석했습니다.

프로젝트 설계부터 데이터 준비 및 전처리, 모델 파인튜닝, 추론과 결과 비교·분석까지 전 과정을 직접 수행했습니다.

## 학습 환경 및 설정

학습은 NVIDIA GeForce RTX 5070 Ti(VRAM 16GB) 환경에서 수행했습니다. 제한된 GPU 메모리에서 Qwen3 8B와 14B 모델을 학습하기 위해 4-bit NF4 양자화와 LoRA를 적용했습니다.

| 항목 | Qwen3 8B | Qwen3 14B |
|---|---|---|
| 학습 방식 | 4-bit NF4 + LoRA | 4-bit NF4 + LoRA |
| LoRA rank / alpha | 16 / 16 | 16 / 16 |
| 학습률 | 0.0002 | 0.0002 |
| 학습 횟수 | 2 epochs | 2 epochs |
| 배치 크기 | 6 | 1 |
| Gradient accumulation steps | 3 | 16 |
| 최대 시퀀스 길이 | 160 tokens | 160 tokens |
| 데이터 사용 비율 | 학습·검증 데이터 각각 10% | 학습·검증 데이터 각각 10% |
