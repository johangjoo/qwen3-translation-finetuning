# 학습 설정

두 YAML은 각각 원본 `train_qwen_lora_sec.py`(8B)와 `train_qwen_14b_lora.py`(14B)에서 추출했습니다. `config.ini`는 원래 학습 코드가 읽지 않아 사용하지 않았습니다.

8B는 train batch 6 / accumulation 3 / eval batch 4, 14B는 1 / 16 / 2입니다. 나머지 주요 설정은 같습니다. 설정 파일의 값은 과거 실행 로그를 대신하지 않습니다.

경로는 실행한 작업 디렉터리 기준입니다. 저장소 루트에서 실행하고, 각 실험에서 `output_dir`을 새 폴더로 설정하세요. 기존 결과가 있으면 실행을 중단합니다. 멀티 GPU·분산 학습은 이 실행 경로의 범위 밖입니다.

기본 `max_length=160`, `packing=true`, 데이터 10% 샘플링은 원본 값입니다. 실제 재학습 전 토큰 길이 분포와 원문/정답이 잘리는지 확인해야 합니다. 값을 변경했다면 원본 실험과 다른 실행임을 결과에 기록하세요.
